## What the receiving checks measure

The separate workstation can run stock KiCad 9.0.9 and open the read-only supplier catalog and public reference data; attempts to read the designer’s project file or the evaluator’s plan were denied. The [drill overlay](../examples/inverter-revision/drill_overlay.py) checks every released drill hit against the actual top paste and mask openings, including partial overlaps. On the earlier frozen edition it found zero of 21 hits under paste. The new whole-board finding was not supplied to the designer or independent persona.

Placement is checked against both the public part-specific library and numbered pads in the **emitted top-copper Gerber**. Using the published 3D-model origin as the midpoint did not change those counts. The [KiCad exporter recommended by JLCPCB](https://jlcpcb.com/help/article/how-to-generate-bom-and-centroid-files-from-kicad-8) also applies a [270° correction for ordinary SOICs](https://github.com/bennymeg/Fabrication-Toolkit/blob/7f627b6be76081b962161b9eb9fe3a326a18c915/plugins/transformations.csv). For the C8269 connector, the [actual manufacturer drawing](https://jlcpcb.com/api/file/downloadByFileSystemAccessId/8757264954276106240) specifies 5.00 mm pitch and 1.50 mm PCB holes.
