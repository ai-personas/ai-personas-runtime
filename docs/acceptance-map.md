# What the Studio evidence establishes

The [pinned design catalogue][catalogue] has **44 criteria: 26 mechanical, 12 behavioral and six conditional extensions**. Each has one row below. These are different from the [46 active and eight retired user requirements][requirements]. A link to implementation means the mechanism exists there; a linked observation describes a particular run. Neither is a product-wide pass.

**What a recipient can already do:** use [Teo’s shift-close register](shift-intake.md), load [Linn’s machine file](stitch-desk.md), take Ada’s unclaimed pickup packet into a vector-cut planner, or slice Mara’s fixture directly from the issued files. Kit’s [top-only EC1 handoff](../examples/ec1-energy-control/reflow/) also passed digital intake on the desk’s exact catalog, placement and probe conventions, with a resistor land-pattern qualification. **What remains open:** whether a freely adopted numerical change makes a later delivery better. Cleo’s corrected board ZIP was still a **NO-GO** for unchanged assembled ordering.
