# What the Studio evidence establishes

The [pinned design catalogue][catalogue] has **44 criteria: 26 mechanical, 12 behavioral and six conditional extensions**. Each has one row below. These are different from the [46 active and eight retired user requirements][requirements]. A link to implementation means the mechanism exists there; a linked observation describes a particular run. Neither is a product-wide pass.

**What a recipient can already do:** use [Teo’s shift-close register](shift-intake.md), load [Linn’s machine file](stitch-desk.md), take Ada’s unclaimed pickup packet into a vector-cut planner, or slice Mara’s fixture directly from the issued files. **What remains open:** whether a freely adopted numerical change makes a later delivery better. Cleo’s corrected board ZIP was still a **NO-GO** for unchanged assembled ordering.

[Mira’s inspection and its return](experience-and-action.md#miras-inspection-and-its-return) illustrates M08 and M17: the action and its returned output were supplied together, but the actual retry cited only the return. Accepting the originally rejected citation on a separate copy did not change that history.

**Reading the numerical evidence:** M02 asks *what changed*. M08 and M17 ask *what was supplied on this actual decision*. M21 follows *what happened afterward and what the persona made of it*. B04 asks *did the numerical difference change a substantive choice?* B09 adds *did the later recipient benefit?* Do not carry a pass from one question into the next.

For future ordinary work, the [private epoch observer](../examples/stitch-desk/README.md#preserving-an-actual-change-during-future-work) retains both model objects and bracketing workspaces. [A timing control](../examples/stitch-desk/observer-packages.json) shows why the two differ: if an activation and rollback both land between samples, both sets of weights survive, but the archives do not contain both active histories. Run the [matched comparison](../examples/stitch-desk/protocol.json) only on an eligible owner-chosen change with both authentic states.
